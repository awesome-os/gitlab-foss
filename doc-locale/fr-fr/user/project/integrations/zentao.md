[ZenTao](https://www.zentao.net/) est une plateforme de gestion de projet web.

Les versions suivantes de ZenTao sont prises en charge :

- ZenTao 15.4
- ZenTao Pro 10.2
- ZenTao Biz 5.2
- ZenTao Max 2.2

## Configurer ZenTao {#configure-zentao}

Cette intégration nécessite une clé secrète API ZenTao.

Effectuez ces étapes dans ZenTao :

1. Accédez à votre page **Admin** et sélectionnez **Développer** > **Application**.
1. Sélectionnez **Ajouter une application**.
1. Sous **Nom** et **Code**, saisissez un nom et un code pour la nouvelle clé secrète.
1. Sous **Compte**, sélectionnez un nom de compte existant.
1. Sélectionnez **Enregistrer**.

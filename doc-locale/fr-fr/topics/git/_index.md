Git est un système de contrôle de version distribué [libre et open source](https://git-scm.com/about/free-and-open-source). Il gère des projets de toutes tailles rapidement et efficacement, et prend en charge la restauration des modifications en cas de besoin.

GitLab est construit par-dessus (et avec) Git, et vous propose une plateforme entièrement intégrée, basée sur Git, pour le développement logiciel. GitLab ajoute de nombreuses [fonctionnalités](https://about.gitlab.com/pricing/feature-comparison/) puissantes par-dessus Git pour améliorer votre workflow.

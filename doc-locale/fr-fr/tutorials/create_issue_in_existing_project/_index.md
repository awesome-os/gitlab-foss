Un [ticket](../../user/project/issues/_index.md) permet de suivre une tâche, un problème ou une fonctionnalité planifiée dans votre [projet](../../user/project/organize_work_with_projects.md). Les tickets servent à planifier le travail et à demander de l'aide. Les tickets peuvent suivre n'importe quelle tâche, pas uniquement les bugs ou les problèmes.

Découvrez comment afficher tous les tickets ouverts dans votre projet et créez-en un nouveau pour signaler un problème que vous avez remarqué.

## Ouvrir la liste des tickets {#open-the-issues-list}

Commencez par parcourir les tickets ouverts dans le projet. Vous pouvez ainsi vérifier s'il existe déjà un ticket pour le problème que vous avez remarqué.

Dans votre projet, dans la barre latérale gauche, sélectionnez **Forfait** > **Éléments de travail**.

![Barre latérale affichant les éléments de menu « Manage » et « Plan » sous l'en-tête du projet. Sous l'en-tête Plan, le lien « Work items » est mis en évidence.](img/sidebar_v18_10.png)

Dans la barre de filtre, sélectionnez le filtre **Type**, l'opérateur **est** et la valeur **Ticket**. Une liste de tous les tickets ouverts s'affiche :

![Une liste de tickets triés par date de création. Un contrôle à points de suspension vertical et un bouton « New items » se trouvent dans le coin supérieur droit.](img/issue_list_v18_10.png)

## Créer un nouveau ticket {#create-a-new-issue}

Vous ne trouvez aucun ticket existant décrivant le bug que vous avez remarqué ; dans cette étape, vous allez donc en créer un nouveau.

Dans le coin supérieur droit, sélectionnez **Nouvel élément**.

![La boîte de dialogue Nouveau ticket affiche les champs « Type », « Titre » et « Description ». Des champs supplémentaires dans la barre latérale, tels que « Personne assignée », « Labels », « Jalon » et « Dates », sont également affichés.](img/new_issue_v18_9.png)

1. Dans la liste déroulante **Type**, sélectionnez **Ticket** si cette valeur n'est pas déjà sélectionnée.
1. Donnez un titre à votre nouveau ticket pour le résumer.
1. Ajoutez une description du travail à effectuer, de l'idée à consigner ou du bug que vous avez trouvé.
1. Si vous savez qui dans le projet doit se voir attribuer cette tâche, sélectionnez une **Personne assignée**. Sélectionnez **assigner à vous-même** si vous avez l'intention de travailler sur ce ticket.
1. Facultatif. Sélectionnez des [labels](../../user/project/labels.md) pour mieux catégoriser votre ticket.
1. Sélectionnez un [jalon](../../user/project/milestones/_index.md) si applicable.
1. Facultatif. Renseignez les champs **Dates** pour préciser quand cette tâche est censée commencer et se terminer.
1. Facultatif. Définissez les **Contacts** pour identifier les membres supplémentaires de l'équipe ou les parties prenantes qui doivent être consultés sur cette tâche.
1. Sélectionnez **Créer un ticket** pour terminer la création du nouveau ticket. La liste des tickets mise à jour s'affiche avec le nouveau ticket inclus.

## Étapes suivantes {#next-steps}

Vous pouvez ensuite :

- Consulter, mettre à jour et commenter votre ticket.
- Utiliser les tickets sous forme de [tableau Kanban](../kanban/_index.md).
- Apprendre à effectuer le [triage des tickets](../issue_triage/_index.md).

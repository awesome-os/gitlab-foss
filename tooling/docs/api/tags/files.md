Use this API to manage [repository files](../../../../doc/user/project/repository/_index.md).
You can also [configure rate limits](../../../../doc/administration/settings/files_api_rate_limits.md)
for this API.

Personal access tokens with the `api` scope have read-write access to repository files. Tokens with
the `read_api` or `read_repository` scope have read access.

Use this API to interact with the [GitLab agent for Kubernetes](../../../../doc/user/clusters/agent/_index.md).

Receptive agents let GitLab connect to Kubernetes clusters that cannot connect to the GitLab
instance. Receptive agents are available only on GitLab Ultimate for GitLab Self-Managed.
